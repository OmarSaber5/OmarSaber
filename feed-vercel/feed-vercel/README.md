# لوحة ضيف للأعلاف — Vercel

## ما الذي تفعله هذه النسخة؟

- لوحة إدارة محمية بكلمة مرور على `/admin`.
- ترفع `master.csv` وكل ملفات العملاء دفعة واحدة.
- تحفظ CSV في **Vercel Blob Private Storage**؛ لا يدخل أحد للملفات برابط مباشر.
- تنشئ لكل عميل رابطًا سريًا ثابتًا يرى منه رصيده وعملياته فقط.

## النشر على Vercel

1. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد إليه.
2. من Vercel اختر **Add New → Project** ثم استورد المستودع واضغط Deploy.
3. من صفحة المشروع: **Storage → Create → Blob → Private**. اربط الـBlob بالمشروع؛ سيضيف Vercel متغير `BLOB_READ_WRITE_TOKEN` تلقائيًا.
4. من **Settings → Environment Variables** أضف متغيرًا اسمه `ADMIN_PASSWORD` وضع كلمة مرور قوية وطويلة.
5. نفّذ Redeploy من صفحة Deployments بعد إضافة المتغيرات.
6. افتح رابط الموقع ثم سجل الدخول بكلمة مرور الإدارة، وارفع `master.csv` وكل ملفات العملاء الموجودة في مجلد `clients` في المرة نفسها.

## الرفع اليومي

افتح `/admin`، اختر الملفات الجديدة (بما فيها `master.csv`) ثم اضغط **رفع وتحديث**. ستبقى روابط العملاء كما هي طالما ظل اسم ملف كل عميل كما هو.

## ملاحظات أمنية

- لا ترفع ملفات CSV إلى GitHub ولا تضعها داخل مجلد `public`.
- الرابط السري للعميل يعمل كـ«مفتاح دخول»؛ أرسله للعميل المعني فقط. إن أردت إيقاف رابط عميل، غيّر اسم ملفه مؤقتًا في الرفع القادم أو اطلب تطوير زر لإعادة توليد الرابط.
- الحد الحالي لكل ملف عند الرفع هو 5MB.
